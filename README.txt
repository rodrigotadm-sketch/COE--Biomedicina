COE-Biomedicina

Arquivos:
- index.html
- styles.css
- app.js
- coe.json

PUBLICAÇÃO
1. Crie um repositório público chamado COE-Biomedicina.
2. Envie os quatro arquivos principais para a raiz.
3. Ative GitHub Pages em main / (root).
4. Use a URL publicada em um iframe no WordPress da UFPR.

ATUALIZAÇÃO
Edite principalmente coe.json para alterar:
- membros
- função na Coordenação
- departamento
- e-mail
- Currículo Lattes
- responsáveis por modalidade de estágio
- links de documentos e orientações
